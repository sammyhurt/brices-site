# berniebrice.com

Bernie Brice's infrastructure engineering portfolio. React + Vite + Tailwind, the same template as the Studios. Hosted on Netlify.

- Every fact lives in `src/site/data.ts` and comes from the resume (`public/Bernie-Brice-Resume.pdf`). Edit that file to add details.
- Tracked application links: `https://berniebrice.com/?for=<code>`. Make them at `/admin` (Studio passcode).
- Contact form: Netlify Forms (form name `contact`).

Build: `npm run build` (output in `dist`).
